# Velocity Motors - Car Website

Open `index.html` in any browser (just double-click it). No server needed.

## Folder layout
- `index.html` - the page
- `css/style.css` - styling
- `js/main.js` - slideshow, filters, lightbox
- `js/data.js` - list of cars and gallery images (edit this to add or change items)
- `images/hero/` - 3 large banner images
- `images/cars/` - full-size car images (12)
- `images/thumbs/` - small card thumbnails (12)
- `images/gallery/` - colour-variant gallery (48)
- `images/icons/` - logo / favicon

## Using your own photos
1. Drop your JPG/PNG/WebP files into the matching `images/` folder.
2. Edit the paths, names and prices in `js/data.js`.
3. Keep thumbnails around 400px wide and full images around 1600px wide so the site loads fast.

The included images are generated placeholder illustrations of generic cars.
